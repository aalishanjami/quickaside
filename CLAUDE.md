# Quickaside

Electron side panel for macOS. It transcribes a live call on the Mac and answers questions about it through the user's own Claude Code CLI (`claude -p`, subscription login, no API key). See README.md for the user-facing guide.

## Layout

- `src/main/main.js`: app lifecycle, windows, tray, IPC, call start/stop, saving. Wires everything below. The app has a Dock icon and a menu bar icon, and the window and prompt hide instead of closing. The window must stay loaded because `index.html` runs the mic. It used to have no Dock icon, and the user found that left no way back to a window behind other apps. The window is `type: 'panel'`, because Electron says a normal window of an app with a Dock icon can't float over another app's full screen. That type stays on all Spaces, and never activates the app by itself, so `win.on('focus')` does that between calls. `createMenu` replaces the default menu, because Reload would drop the page running the mic.
- `scripts/build-helpers.sh` compiles the Swift helpers into `bin/`, targeting macOS 14.2.
- `scripts/calendar-helper.swift` + `src/main/calendar.js`: reads the current event through EventKit, off until `useCalendar` is on. `pickEvent` chooses the event, and `matchProject` only fires on one clear match. A bare tool has no Info.plist, so the usage text is linked into the binary from `scripts/calendar-helper.plist`.
- `scripts/call-detector.swift`, in `bin/call-detector`: prints which apps have the mic open as JSON lines, from Core Audio's process list (`kAudioHardwarePropertyProcessObjectList`, macOS 14.2+). Reads no audio and needs no permission. `src/main/call-detector.js` matches bundle ids against known call apps (prefix match, since Electron apps capture from a helper), and needs 3 s open to count and 15 s closed to end. A call started from a detected app ends with it. Without the helper everything else still works.
- `src/main/audio/system-audio.js`: spawns AudioTee (`node_modules/audiotee/bin/audiotee --sample-rate 16000 --chunk-duration 0.1`), Core Audio taps, macOS 14.2+. Needs "System Audio Recording Only" permission; without it AudioTee records pure silence, no error.
- `src/renderer/mic.js`: mic via getUserMedia, AudioWorklet loaded from a Blob URL (file:// worklet modules are unreliable), 16 kHz Int16 chunks over IPC (`mic:pcm`).
- `src/main/audio/segmenter.js`: adaptive-energy VAD, cuts on 650 ms pauses, soft max 7 s, hard max 14 s.
- `src/main/transcriber.js`: prefers `whisper-server` (kept running, POST /inference multipart, response_format=json), falls back to `whisper-cli` per segment (`-nt -np -sns -otxt -of`). Cleans annotations and classic hallucinations.
- `src/main/transcript.js`: lines sorted by start time; drops mic lines that echo a "them" line said at the same time, and a short line past its second word-for-word repeat on one side, because Whisper invents those. Questions and words like "yeah" are exempt.
- `src/main/claude.js`: one persistent `claude -p --input-format stream-json --output-format stream-json --verbose --include-partial-messages --safe-mode --no-session-persistence --strict-mcp-config --tools "" --system-prompt-file ...` process per call. Flags are feature-detected from `claude --help`. First message sends the full transcript, later ones only unsent lines. Cancel kills the process; the next question starts fresh. Every question from them gets an answer: `maybeAutoAnswer` queues instead of dropping, and `looksLikeQuestion` catches questions with no question mark. Files opened with Read, and files matched by a content Grep, are shown on the answer as its sources.
- `src/main/log.js`: rotating log in `app.getPath('logs')`. Record states, counts and timings only, never transcripts, answers, notes or prompts. Report a problem (Settings > Help) shares `diagnostics()` from `main.js`.
- `src/main/updater.js`: Electron's `autoUpdater` against update.electronjs.org, which needs a public repo. It never checks or installs during a call. It stays off until `app.isPackaged` is true, and that needs the executable renamed from `Electron`, which `build-mac-app.sh` does. `QUICKASIDE_TEST_UPDATE_FEED` points it at a local stand-in for the update service.
- `src/renderer/setup.*`: first run, three steps, as a page in the one window. The speech model downloads behind the steps once the first is done, because a step of its own was minutes of waiting. `setupDone` is true for settings files from before it existed. The call audio step plays a tone and needs real samples, because AudioTee records pure silence with no error when the permission is missing.
- `src/main/calls.js`: the library. One JSON file per call in `userData/calls`, not in the save folder, because a blocked read of Documents hangs the main process and a renamed app starts with no grant there. The markdown in the save folder is the user's copy. Also `talkStats`, and `parseMarkdownCall` for calls saved before the library. Imports match on the file as well as the id, or every call appears twice.
- `src/main/notes.js`: the after-call notes, one `claude.once()` returning JSON. `src/renderer/library.*` is the Past calls window.
- With Save each call off, nothing is kept: no record, no file, no notes. `call.file` is the switch. Deleting a call also clears `call.file`, because the last call is saved again when the next one starts, which would bring it back.
- `src/main/assist.js`: Fill in for me, Find my projects and the spark buttons. One `claude.once()` call fills any set of fields and returns JSON.
- `src/main/claude-memory.js`: reads Claude Code's own memory (`~/.claude/projects/*/memory/*.md` and `~/.claude/CLAUDE.md`) for those drafts only. It must never reach a live call, because it covers every client and could mix them, and a test enforces that. It skips links, since one could point at a folder macOS guards. Claude chat memory lives in the user's account with no API, so the Projects page takes a paste instead.
- Projects: `settings.projects` holds `{ id, name, brief, folder, files }`, and `activeProject` is the one in use. Projects are optional, and nothing may assume a notes folder exists. Find my projects adds what it finds at once, with Undo: it used to show a ticked list that saved nothing until Add selected, so real users lost it when Settings closed. After a call with no project, the notes also name the client, and the app offers to save it (`saveCallProject`). A project left blank stays out of the dropdowns and is dropped at the next launch. `fillProjects` rebuilds only when the list changes and sets the value only when it differs, because either one closes an open menu. The brief and files load when Claude starts, and `buildSystemPrompt` adds a rule against using other clients' facts. A project folder only counts inside the notes folder, because that is the one folder macOS access is checked for: anywhere else Claude could freeze on a prompt. Changing project mid-call restarts Claude, which resends the transcript. A finished call is saved again when the next one starts, so the project and note are kept on `call`, not read from the dropdown. The note is held in memory only.
- `src/connector/`: a read-only MCP server, so the user's own Claude Code or Claude Desktop can search saved calls. `server.js` is hand-written stdio JSON-RPC (no SDK, to keep the no-runtime-deps rule) and `tools.js` holds the five tools, on top of `CallStore`. It reads files directly, so the app need not be running. `settings.connector` is the kill switch: the server reads it on every tool call and anything but `true` refuses, so turning it off works even where the server is still set up. The app's own Claude never sees it (`--strict-mcp-config`). Transcript pages stay under 30,000 characters, because Claude Code warns above 10,000 tokens from one tool. Nothing may write: a transcript holds other people's words, so a planted instruction must have nothing to act on.
- `src/main/connector.js`: sets it up, only on a click in Settings > Connect. Claude Code gets `claude mcp add-json --scope user`, with the app's own binary and `--connector` as the command, so nobody needs Node. Add fails if the name exists, so connect removes first. Status comes from `claude mcp get`, which exits 0 even when its health check fails, so it reads the Status line. Claude Desktop gets a `.mcpb` it opens by itself, run on its own Node. Build it with `zip -D`: the official unpacker fails on the folder entries `ditto` writes. `importOldCalls` runs when the switch turns on and at launch, or calls from before the library would be missing.
- `src/main/prompts.js`: system prompt. Its first rule forbids claiming anything about the user or company that is not in About you, context files, folder notes or the transcript, and requires numbers and status as written (earlier versions invented timelines and past projects, and turned "47 workflows read" in a test into "built 47").
- `src/renderer/`: UI (no framework, no bundler, CSP `script-src 'self' blob:`). `index.html`, `app.js`, `styles.css` are the panel: frameless, no traffic lights, newest answer on top in large type, so streaming text stays still and the words sit near the webcam. The transcript is folded behind the footer until asked for. `prompt.*` is the small call prompt. `settings.*` is one page for You, Calls and Help, and another for Projects. `library.*` is Past calls. `theme.css` and `ui.js` are shared. Macs only, so fonts are the system's Avenir Next and DIN Alternate. Signal yellow is always a fill with ink on it; use `--signal-text` for yellow words.
- One window. `main.js` keeps a `view` (now, calls, projects, settings, setup) and a `shape` (panel, wide, setup), and `applyLayout` moves between them. `index.html` draws the title bar and sidebar and runs the mic. Library, Settings and setup are `WebContentsView` pages laid over it, created when first opened. They never need a drag region, because the title bar stays in `index.html`. Native red, yellow and green buttons. Red hides. Yellow really minimizes, because a macOS window can't be stopped from going to the Dock, and the mic keeps running through both. Only the panel floats, or the wide window would cover what the user went to look at. So a macOS permission prompt can leave the wide window behind other apps, and `bringBack` runs after each prompt the user asked for. A call start always returns to the panel, and the call prompt shows unless the panel or a focused window already offers Start.
- The small bar is the panel shrunk to its title bar (`minimizePanel` in `main.js`), from the button shown on a call. `panelFull` keeps the real size, so `panelBounds` never saves the small height. A dot on the button means an answer came in meanwhile.
- `src/main/window-layout.js`: where the window goes. Panel top right, prompt in the corner. The wide shape grows from the panel's side of the screen, so the panel can return to the same spot.
- `scripts/build-whisper.sh`: builds whisper-server v1.9.5 with Metal into `~/Library/Application Support/Quickaside/bin`. Homebrew's whisper-cpp formula is built with the server off.
- `src/main/index.js` and `src/main/launch.js`: the entry point, so it runs before anything reads a switch or a test variable. A release refuses every switch except `--connector --data` and drops every `QUICKASIDE_*` variable. `--connector` serves `src/connector` from the app's own binary, beside the running app, with its own temp folder as userData.
- `scripts/build-mac-app.sh`: copies Electron.app, adds `src` and `node_modules/audiotee` under Resources/app, renames the executable (the helper apps keep their Electron names, because Electron looks for those first), sets bundle name/id plus NSMicrophoneUsageDescription and NSAudioCaptureUsageDescription, copies the licences into `Resources/licenses`, signs through `sign-mac-app.sh`, installs to `~/Applications`.
- `README.md`, `PRIVACY.md`, `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `CHANGELOG.md`, `NOTICE` and `.github/`: the public project files. The README is for people using the app, and developer notes live in CONTRIBUTING. `PRIVACY.md` and `SECURITY.md` are promises, so change them in the same commit as anything that changes what is kept or sent. `docs/panel.png` is a real test call with made-up details. `NOTICE` must list whatever ships, so update it with `whisper-server` or anything new in the bundle. Blank issues stay on, because Report a problem opens one with `?body=`. `test/unit/docs.test.js` guards these.
- `site/`: the public website, one page plus a privacy page, as plain files any static host can serve. It is live at `quickaside.vercel.app`, because the user chose not to buy a domain. The Vercel project `quickaside` serves `site/` with no build step and is not connected to the repo, so a push doesn't change the site: a new deployment from `aalishanjami/quickaside` main does. `privacy.html` and the images are made from `PRIVACY.md` and the originals by `scripts/build-site.js` (`npm run site`), and a test fails if they fall behind. `build/og.html` draws `og.png`. `PRIVACY.md` promises the site loads nothing from other sites, which its CSP enforces, so no web fonts or analytics. Keep it from selling hiding: the suit against Granola is about recording without disclosure, so the consent box stays and "Hide from screen sharing" stays off the page.
- `scripts/make-icon.js` (`npm run icon`): draws `build/icon.icns`, the menu bar images and `src/assets/icon.png` from `build/icon.svg`, `build/icon-small.svg` (16 and 32 px only) and `build/tray.svg`. The results are committed, so a normal build doesn't need it. The mark is a disc and a closing parenthesis: the call, and an aside at its side. Keep the tile the full macOS rounded square, because macOS 27 puts any other shape on a grey plate, as it did with Electron's round icon. There is no Xcode here, so it is a plain `.icns`, not an Icon Composer file.
- `scripts/release-mac.sh`: the public build, run on this Mac because the signing key stays here. We don't pay for the Apple Developer Program, so there is no Developer ID or notarization. Hardened runtime, signs every Mach-O one by one, innermost first, because `--deep` leaves loose tools ad-hoc. It refuses any certificate but the one `install.sh` pins, and packs a zip. `build/entitlements.*.plist` go with it. With no Team ID, anything that loads its own libraries needs `disable-library-validation`, ShipIt included: it crashes at launch without it, after the app has already quit.
- `scripts/install.sh`: the one-line install, `curl ... | bash`. Files fetched by curl have no quarantine, so Gatekeeper doesn't stop them, and a browser download needs Open Anyway instead. It checks the signature against the pinned certificate before touching the installed app, and installs to `~/Applications`, so no password. `REPO` in it must match `bugs.url` in `package.json`, and a test enforces that.
- `scripts/sign-mac-app.sh`: signs with the local identity when it exists, otherwise ad-hoc. Falls back to ad-hoc if the identity fails, so a build never breaks over signing.
- `scripts/create-signing-identity.sh`: optional, one time. Self-signed code signing certificate in its own keychain at `~/Library/Application Support/Quickaside/signing/`. It stays out of the login keychain and search list and sets no trust, so it needs no password prompt. Uses `/usr/bin/openssl` because Homebrew's OpenSSL 3 writes a .p12 that `security import` cannot read.

Runtime data: `~/Library/Application Support/Quickaside/` (settings.json, models/, bin/whisper-server, claude-cwd/). Transcripts: `~/Documents/Quickaside/` by default.

## Commands

- `bash setup.sh`: one-time Mac setup (deps, whisper-server build or brew whisper-cli fallback, model download, .app build).
- `npm start`: dev run. Launch from Terminal.app; in this mode Terminal holds the mic and system audio permissions.
- `npm test`: unit tests (`node --test`), no Mac needed. Fakes for `claude` and `whisper-cli` live in `test/fixtures/`.
- `xvfb-run -a node test/e2e/run.js <outDir>`: full app with a synthetic call and a stand-in whisper-server (needs Playwright and a signed-in `claude`). `E2E_REAL_MIC=1` routes audio through Chromium's fake mic, `E2E_AUTO=1` tests auto-answers.
- Test without a call: `QUICKASIDE_TEST_AUDIO_THEM=them.wav QUICKASIDE_TEST_AUDIO_YOU=you.wav npm start`. `QUICKASIDE_WHISPER_URL` points at an external whisper-server.
- `TEST_BUILD=1 bash scripts/release-mac.sh`: a hardened, signed build that keeps the test switches and `--remote-debugging-port`, and is never packed. A release refuses both, so drive this one instead.

Quit must end with `app.exit(0)`, not `app.quit()`. With nothing to save, the async cleanup finishes in microtasks, so `app.quit()` runs inside the first `before-quit`, and that handler's `preventDefault` then cancels the quit after the windows have closed. The old `window-all-closed` handler hid this. Without it the app stays alive with no windows.

When testing on a Mac: `pgrep -f` matches your own shell if the same command line holds the pattern, so match the app by `ps -axo pid=,comm=`. A locked screen makes the window server's list meaningless, so ask Electron with `isVisible()`. To tell if it is locked, read `CGSSessionScreenIsLocked` from `CGSessionCopyCurrentDictionary()`: the user can be driving this session from another device while the Mac sits locked.

## Conventions

- No runtime npm dependencies besides audiotee. Keep it that way unless there is a strong reason.
- App copy and prompts: short, plain words, no em dashes.
- macOS ships bash 3.2: keep shell scripts free of bash 4+ features (no `mapfile`, no `${var,,}`, careful with empty arrays under `set -u`).
- Ideas not built yet: interim (partial) lines during long monologues, speaker separation within "Them", Windows support.
